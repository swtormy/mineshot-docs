# План выпуска первой версии

Верхний уровень. Подробности, задачи и промпты для артов — в `docs/05-roadmap.md`.

Реализацию делаю я. Картинки и текстуры генерируете вы по промптам из роадмепа.

Первая версия = loop + магазин + завал + сейв на аккаунт Telegram + тестовые ссылки. Не магазины приложений.

```
Правила на бумаге
        ↓
Список артов (вы генерируете)
        ↓
Каркас игры в браузере
        ↓
Тап → руда → магазин → завал
        ↓
Сейв, офлайн, достижения, языки
        ↓
Сок, звук, ваши картинки
        ↓
Тестовый HTTPS + бот Telegram
        ↓
Узкий круг → правки → v1
```

## Шаги

| Шаг | Что | Готово, когда |
|---|---|---|
| 0 | Правила на бумаге | ТЗ на сцену и формулы |
| 1 | Каркас Vite + Phaser | Открывается на телефоне в браузере |
| 2 | Список артов и звуков | Есть файлы или заглушки, промпты в роадмепе |
| 3 | Игровой удар | Минуту тапать уже приятно |
| 4 | Магазин и несколько руд | Первое улучшение за минуту |
| 5 | Завал | Читается, хочется тапнуть снова |
| 6 | Сейв, офлайн 8 ч, достижения, RU/EN | Закрыл — открыл, прогресс на месте |
| 7 | PWA + бот + Mini App | Круг заходит с телефона в Telegram |
| 8 | Обкатка | Вечер без критичных дыр = v1 |

После v1: Android/iOS, свой домен, шаринг, платежи, вторая шахта.

Идти по порядку: Telegram не раньше, чем в браузере живут удар, магазин и завал.
